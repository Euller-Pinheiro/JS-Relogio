# Relógio analógico

Relógio analógico que acompanha a hora do computador. Os ponteiros giram com `transform: rotate`, calculado a cada segundo em JavaScript.

Projeto de estudo de 2023 (JavaScript), mantido aqui como registro da minha evolução.

## Como rodar

Abra o `index.html` no navegador.

## O que pratiquei

- `setInterval` e o objeto `Date`
- Transformações CSS (rotação e origem)
- Conversão de horas, minutos e segundos em ângulos
